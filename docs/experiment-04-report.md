# 实验四：登录、权限与 AI 安全

## 实验目标

实现登录、基于角色的访问控制、JWT 签发与校验，并建立 AI 安全意识。

## 完成内容

- 新增用户、角色、权限、用户角色、角色权限表。
- 使用 Spring Security 保护接口。
- 使用 BCrypt 存储默认用户密码。
- 登录接口 `/api/auth/login` 签发 JWT。
- JWT 过滤器从 `Authorization: Bearer <token>` 中解析身份。
- 管理员和图书管理员可以写入图书；读者只能查询。
- 新增用户管理、借阅流转、逾期提醒、图书分类和封面上传，强化 RBAC 与实际业务场景。

## 默认账号

- admin / admin123：ADMIN，拥有读写删权限。
- reader / reader123：READER，仅拥有查询权限。

## 安全说明

真实项目中应通过环境变量配置 `JWT_SECRET`，不要把生产密钥提交到仓库。用户输入进入模型前应做长度限制、敏感信息过滤和提示注入防护；模型输出需要人工兜底与来源核验。

## 验证方式

```powershell
mvn test
```

测试覆盖登录、JWT 访问图书接口、管理员 CRUD、读者写入被拒绝。

## AI 工具使用记录

使用 AI 辅助生成 Spring Security、JWT、RBAC 代码和测试；人工检查密码哈希、权限规则和测试结果，避免提交未理解代码。
